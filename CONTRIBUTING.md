# Contributing

Keep changes focused and run `scripts/Build.ps1` before opening a pull request.
Add a regression check for changed behavior. Keep 8K described as experimental
until actual sender output has been measured. Report tested hardware and OS
versions without including private identifiers.

Never commit receiver binaries, diagnostic reports, configuration files,
screenshots of personal content, tokens, passwords, debug symbols or build output.
Avoid machine-specific paths in scripts and use a GitHub no-reply address for
commit authorship if you want to keep your email private.

Do not copy proprietary app code or artwork. Contributions must be compatible
with GPL-3.0-or-later. Preserve attribution for third-party material.
